`Power BI` `DAX` `Modelagem de Dados`

### 📈 Dashboard de Análise de Vendas
Dashboard desenvolvido para análise de **vendas, produtos e clientes**, utilizando relacionamentos entre tabelas e indicadores de desempenho.
